# 機能一覧

| 機能 | 動作 |
| --- | --- |
| 歌声 / 話し声 | 追従窓・音符境界を切替。ピアノは両方「ピアノ（鍵盤の音程）」が初期設定 |
| 一操作の録音 | マイク許可・PCM保持・暫定音程表示を同時開始。最大60秒 |
| 音声ファイル入力 | 60秒/20 MiBまでを端末内decode。metadata先行検証、冒頭から解析、中止/失敗時は直前の結果を保持 |
| 音程タイムライン | 前後の安定した声へ20ms以内に戻る大きな急落を限定補正した青線と近傍半音の薄いバー。音名も共通補正。固定レンジ、空白保持 |
| 録音後の再解析 | 元PCMとサンプル時計を保持し、前後の候補と短窓で見直す。分析中は実進捗を表示。分析だけの失敗時は元音声を残して再試行 |
| 初期雑音後の長音保持 | 強い現在周期性から過大な雑音量を見直す。声を雑音学習せず、有声判定できた即発声も保持。一次候補・判定理由は開発用フレーム記録へ残す |
| 元の声の再生 | PCM AudioBufferで再生、共通カーソル |
| ピアノ再生 | 固定した鍵盤の音程で打鍵・自然減衰。必要な鍵盤のサンプルをデコードし、ループしない。声の揺れを聴く連続音高は再生設定から選択。30ms未満の孤立音除外・短い境界の倍音候補補正・原音/原軌跡保持は維持 |
| 鼻歌のメロディ音符 | 歌声の音高列から音符の区切りを推定。表示/ピアノと共通の20ms以下の急落補正、揺れの過分割抑制、強い音量谷の同音再発音。内部の原音高は保持 |
| 推定楽譜・カタカナ | 録音後の五線譜、固定ド（ド4＝中央ド）・♯表記。4/4・16分単位、テンポ候補/仮120と40〜240 BPMの調整、休符・タイ・小節送り |
| 譜面どおりに聴く | 表示と同じ音符・休符・タイを通常のピアノで再生。離鍵後120msの余韻は音符長やMIDIに加算しない。テンポ変更と同期、原音側再生と相互停止。原タイムラインとは別の譜面時計 |
| 記譜時の不要な再打鍵抑制 | 短い別音の省略後に接する同音を、元の音符列も連続する場合だけ結合。実休符・同音再発音は保持。元Hzは変えない |
| 任意の再採譜 | Basic Pitchの音符活動/onsetを単音化し、元の推定と選択・比較。Worker/WASMを必要時に取得。失敗/中止/録り直しで古い結果を反映しない |
| 音符編集 | 五線譜/一覧から選択、音程/開始/長さ、休符化/追加、50件Undo/Redo、自動推定に戻す。原音/F0は変更しない |
| MIDI保存 | 共通ScoreをSMF format 0、480PPQ、ピアノへ出力。音高/音価/テンポ/タイ/休符を譜面再生と共有 |
| 再生位置 | 停止中のスライダーで指定、再生中はAudioContext時計へ同期 |
| エラー復帰 | マイク拒否、取得取消、音源ロード失敗・再試行、音声中断を明示 |
| 入力設定の確認 | ブラウザが報告する実適用値を表示 |
| ローカル処理 | 音声を外部送信しない。永続保存なし |

ターゲット合わせ、基準音、スコア、旧ダミー音階はIssue #13の目的に従い主アプリから除外。アカウント、SNS共有、PDF書出し、原曲取得、伴奏分離は対象外。MIDIと最小音符編集は後続のサービス品質要求に基づき追加したもので、自動採譜の精度改善とは別に評価する。

自動検証と未検証の区別は [検証報告](evaluation/verification.md) を参照。UI設計は [UI設計.md](UI設計.md) が現行で、旧.penファイルを現行デザインとは扱わない。
