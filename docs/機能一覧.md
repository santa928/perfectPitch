# 機能一覧

| 機能 | 動作 |
| --- | --- |
| 歌声 / 話し声 | 追従窓・音符境界を切替。ピアノは両方「元のズレを残す」が初期設定 |
| 一操作の録音 | マイク許可・PCM保持・暫定音程表示を同時開始。最大60秒 |
| 音程タイムライン | 連続音程の青線と近傍半音の薄いバー。音名軸、固定レンジ、空白保持 |
| 録音後の再解析 | 元PCMを保持して同じサンプル時計で見直す |
| 元の声の再生 | PCM AudioBufferで再生、共通カーソル |
| ピアノ再生 | 鍵盤に丸める / 元のズレを残すピアノ風の2種類。30ms未満の孤立音を除き、短い境界の倍音候補を限定補正。原音/原軌跡は保持 |
| 推定楽譜・カタカナ | 録音後の五線譜、固定ド（ド4＝中央ド）・♯表記。4/4・16分単位、テンポ40〜240 BPM、休符・タイ・小節送り。表示専用 |
| 再生位置 | 停止中のスライダーで指定、再生中はAudioContext時計へ同期 |
| エラー復帰 | マイク拒否、取得取消、音源ロード失敗・再試行、音声中断を明示 |
| 入力設定の確認 | ブラウザが報告する実適用値を表示 |
| ローカル処理 | 音声を外部送信しない。永続保存なし |

ターゲット合わせ、基準音、スコア、旧ダミー音階はIssue #13の目的に従い主アプリから除外。アカウント、SNS共有、MIDI書出し、原曲取得、伴奏分離は対象外。

自動検証と未検証の区別は [検証報告](evaluation/verification.md) を参照。UI設計は [UI設計.md](UI設計.md) が現行で、旧.penファイルを現行デザインとは扱わない。
