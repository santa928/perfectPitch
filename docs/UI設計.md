# UI設計 — 声の音楽ノート

## 世界観辞書

明るい紙色の背景、白いノート面、濃紺の文字、青い声の軌跡、薄青の鍵盤バー、朱色の録音・再生位置。音楽ノートの比喩を背景・タイムライン・凡例・操作に揃える。ターゲット・正解・スコアという語彙を主画面に持ち込まない。

## レイアウトとアンカー

上から「歌声/話し声と状態」→「音名タイムライン」→「録音/停止」。録音操作はタイムラインの下端に続く通常フロー内に置く。停止後は、その下へ聴き比べを展開する。フローティングHUDや比率による絶対配置は使わない。

タイムラインはCanvas内の左48pxを音名、右18pxを余白、上22px/下30pxを目盛りの安全余白に確保。`plotBounds()`とDOM計測で下端・右端の収まりを確認する。空状態案内のみCanvas内へ重ねるが、操作要素は含まない。

狭い画面はグリッドを1列へ戻し、カード・設定・説明は内容の高さに追従する。録音ボタンは幅いっぱい。凡例と音域選択は見出しにアンカーする。モバイルのタイムライン高さは主操作が初期viewportに収まる実測を基準に選ぶ。

## 情報設計

- メイン: 声の種類、実測軌跡、録音/停止、処理状態。
- 停止後: 元の声/ピアノ、一つの再生、再生位置。
- 停止から結果確定までは「分析中 N%」と前後の音を確認する案内を表示。実進捗を使い、録音ボタンも「分析中…」として無効化。新しいモーダルや画面は追加しない。
- 分析だけ失敗したときは、元の声の再生と「元音声から再解析する」の再試行先を明示する。
- 詳細: ピアノ音高モードと再解析、音源状態。
- 録音後の追加パネル: 聴き比べの下の「楽譜とドレミを見る」。紙色の五線譜に紺色の音符と固定ド音名を添える。テンポ入力・推定の説明・4小節・前後操作の順に通常フローへ配置する。
- 鼻歌の楽譜には「譜面どおりに聴く」を追加し、同じ音符と長さのピアノを鳴らす。テンポ候補と仮120を区別。テンポ入力→候補の説明→再生ボタン/状態→五線譜の通常フローとし、再生部分は子要素の自然な高さと8px gapで配置する。
- 譜面再生は元音声と別の拍時計で、声のタイムラインを動かさない。原音再生とは相互停止。読み込み中/再生中は同じボタンで停止でき、テンポ変更/閉じる/録音で止める。失敗時は同じボタンの再試行先を案内する。
- 補足: 対応条件、録音の消去、音声のローカル処理、音源外部通信、入力の実適用設定。
- 周期性・RMSなどを正解率として表示しない。
- 録音の横に「音声ファイルを開く」を配置し、容量/時間/対応形式を短く案内。input/decodeは段階の文言、音程解析は実進捗。中止ボタンは処理中だけ表示し、旧結果を保持する。
- 歌声の譜面に任意の「途切れを抑えて採譜」を置く。初回取得量、元の推定との選択、速い音の限界を操作近くに示す。失敗/中止時は直前の譜面を保持。推定ごとに編集を保持し、再解析/ファイル読込の成功や録音開始で消えることを案内する。
- 小節送りの下にMIDI保存と折りたたみ式の最小編集フォームを置く。音符クリック/キーボード/一覧選択を用意し、音程・小節・拍・長さとUndo/Redoを通常フローに配置。手直し後のテンポは演奏速度だけを変える案内に切り替える。
- 無声/判定不能は線を分断。表示範囲外を端へ押し込まず案内を出す。
- 縦軸は固定。低・中・高・全音域を利用者が明示切替。横軸は8秒表示、録音中のみ追従。

## 操作とアクセシビリティ

ネイティブbutton/radio/select/range/detailsを用い、disabledは実際の操作制御に反映。キーボードfocusを明示。処理/失敗メッセージはrole=status、音名はCanvasと別のテキストでも表示する。Canvasは意味を説明するラベル付き。全録音の音程をスクリーンリーダーだけで時系列に探索する機能は未実装。

## 証拠

楽譜はSVG内の音符・符幹の下へカタカナの共通行を設ける。低音の加線・高音・臨時記号を含む表示を検査し、文字の必要幅が画面を超える小節はキーボードでも横スクロールできる。視認できる文字を縮小して収めない。SVGごとに小節と音名の読み上げラベルを付ける。

375×812と1280×720のDocker Chromiumで確認し、[検証報告](evaluation/verification.md)へ画像と測定を残す。これを実機iPhone/Androidの確認とみなさない。旧 `design/perfectPitch-ui.pen` は保管資料で、本書が現行。
