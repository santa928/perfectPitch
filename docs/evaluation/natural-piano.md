# 固定音程と自然減衰のピアノ再生

## 対象と変更

2026-09-08。比較元は `ffcc602`。初期設定が連続音高で、通常の鍵盤では出せない中間音へ滑ることと、ピアノサンプルの途中を持続ループしていたことを変更した。

- 歌声・話し声の初期設定を「ピアノ（鍵盤の音程）」へ変更。譜面再生にも同じ発音処理を使用する。
- A0〜C8の既存88鍵から必要な鍵盤だけをデコードし、そのサンプルを固定音程・ループなしで再生。3msの立ち上がりでクリックを抑え、元の打鍵と減衰を残す。
- 離鍵後120msで消音し、その余韻まで終了を待つ。途中再開では経過したサンプル位置から再生する。
- 従来の連続音高は設定から明示選択できる。解析・音符区切り・譜面・MIDI・元PCMの処理は変更していない。
- 音源の取得先・ファイル・ライセンス・依存は同じ。取得データと成功した鍵盤を再利用し、欠損・デコード失敗後は再取得できる。外部JavaScriptは実行しない。

## 同じ音符による比較

保存済みの譜面を再解析せず、同じ音符のJSON・テンポ・発音時刻から変更前後のWAVを生成した。JSON一致を検査し、前後とも不正値・クリッピングは0。提供録音からの譜面・音符列・WAVはGitや配布物に含めていない。

別にA4を4.3秒押した条件で、同じサンプル・同じゲインを比較した。値は正規化や音量合わせ前の出力PCM。音質の主観評価や実ピアノとの一致率ではない。

| A4のRMS | 変更前 | 変更後 |
| --- | ---: | ---: |
| 打鍵50〜150ms後 | 0.0170455 | 0.0170455 |
| 打鍵2.9〜3.0秒後 | 0.00328545 | 0.000302165 |
| 後半 / 冒頭 | 約19.3% | 約1.8% |
| 離鍵150〜200ms後 | 0 | 0 |

新しい通常再生はサンプル本来の減衰を残すため、長音でも同じ区間を繰り返さない。声の揺れを聴く連続モードの±30 centsとオクターブのしゃくりは、従来の実PCM検査で2 cents以内を維持した。

## 再現と限界

既存Docker環境と `output/piano.js` / `output/test-voice.wav` を準備したうえで、関連検査を実行する。

```sh
docker compose -f docker-compose.test.yml run --rm --no-deps browser sh -c 'node --experimental-strip-types --test tests/player.test.ts tests/playback.test.ts && npm run build && npx playwright test tests/browser/piano-output.spec.ts tests/browser/studio.spec.ts'
docker compose -f docker-compose.test.yml run --rm --no-deps browser npx playwright test tests/browser/melody.spec.ts --grep '鼻歌の譜面を同じ音符|譜面音源の失敗'
```

WebKitでは `piano-output.spec.ts` だけを対象とし、`browserName: 'webkit'`、Chrome専用の `launchOptions.args` なしで実行する。既存のマイク試験用設定に `--browser=webkit` を追加するだけでは実行できない。

音高解析・音符推定・記譜のソースに差分がないため、大きな実歌唱コーパスの精度比較は再実行していない。変更した場合はその比較を再実行する。新しい依存やモデル取得はなく、Lighthouseも今回は対象外。公開URLへの確認はマージ・公開前のため未実行で、公開時に確認する。

物理iPhone / Androidの再生遅延、出力機器による聞こえ方、ピークメモリ、本人の音色の好みは未確認。長音はサンプル末尾で無音になり、短い休符には最大120msの余韻が重なる。共鳴・ペダル・強弱別の多層サンプルは追加していない。自動採譜に残る音程・休符・リズムの誤りを解消した変更とは扱わない。
