# 一瞬の低音への急落を抑える補正

2026-09-08。利用者の写真3枚に見られる急落への修正。公開前に最新main `a455865` の採譜・音符編集・自然なピアノ再生へ統合した。写真の元PCMは未提供であり、撮影時の音響的な原因や同じ録音での改善は未確認。

## 原因と採用範囲

旧表示は原PitchFrameを直接使用し、音符側の内部補正は両隣が一致する1フレームの約12半音の飛びだけだった。19半音の10ms急落を含む既知の検出列で、不要な低音を含む3音になることを修正前テストで再現した。現在の候補比較・録音後見直しの後にも使える派生補正とする。

初版では40ms以内を対象にしていたが、最新の既存回帰テスト2件で、雑音を含む100msの本物の低音が解析窓により30〜40msだけ観測され、それまで消えることを検出した。実音を優先して対象を20ms以内へ狭めた。音符専用の旧補正と楽譜の量子化は別処理である。

`src/analysis/continuity.ts` は次の全条件を満たす部分だけ、前後の連続音高を時刻に沿って補間する。

- 直前の声より10半音以上低く、20ms以内に直前と0.5半音未満の差へ戻る。
- 前後それぞれ約30msの声がアンカーから0.5半音未満で安定する。
- 有声フレームが連続し、間隔は15ms以下。無声、不明、欠落を跨がない。

タイムライン、表示音名、ピアノ、話し声と歌声の標準採譜で共有。原PCMと原frames・時刻・音量・周期性は変更せず、補正箇所のMIDIとHzだけを派生生成する。手動編集と任意モデルの再採譜結果は変更しない。録音中は後続の支持音が揃うまで暫定の急落が見える可能性があり、補正は遡って反映される。

## 要件差分と受け入れ条件

| 区分 | 内容 |
| --- | --- |
| 維持 | REQ-001〜020。元PCM・原解析値、30ms以上の観測低音、休符、滑らかな下降、最新の採譜/編集/MIDI/自然なピアノを維持 |
| 追加 | REQ-021。10〜20msの内部急落を表示/音名/ピアノ/標準採譜で限定補正 |
| 保留・削除 | なし。元PCMでの効果・実機マイク・採譜精度の未達は継続 |

受け入れ条件: 短い急落を除き、雑音を含む100msの実音、無声/不明/欠落、cents・時刻・原値を保持する。標準採譜と表示の補正を同期し、編集済みの音符を変えない。

非対象: 長い誤推定の自動訂正、前後の支持がない発声境界の低音の除去、発声意図の完全な判定。

リスクと対策: 同じ形の20ms以下の本物の低音とは完全には識別できない。前後の支持と短い時間制限で補正を限定する。境界の単発低音や長い急落は残る。提供PCMでの比較が必要。

性能目標: 既存60秒上限、解析窓、10ms hopを維持。追加処理はフレーム列への線形走査と近傍確認。物理端末での描画CPUとピークメモリは未測定。
