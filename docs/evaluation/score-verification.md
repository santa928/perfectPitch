# 推定楽譜・固定ド表示の検証（2026-09-06）

基点はPR #14マージ後の `0d0948f92be1bd4dc0aeb081b430ceba84b3b908`。追加依頼は「楽譜化、カタカナのドレミを添える」。Issue #13の解析精度・実機評価の未達は本変更でも未完了のまま。

## 設計と採用理由

既存の半音音符から表示専用の楽譜を派生する。原PCM・PitchFrame・ピアノ再生の時間は変更しない。4/4・16分単位、最初の検出音が1拍目、BPM120は仮値で40〜240へ調整可能。短音が丸めで消える場合は件数を出す。小節の末尾を休符で埋め、長音の分割だけをタイで繋ぐ。固定ドの数字はオクターブ、異名同音は♯へ統一する。

時間比例だけの五線譜は音価を読めないため、明示した仮テンポによる推定表示を採用。記号の手描きは加線・臨時記号・連桁・タイの保守範囲が大きいため、VexFlow 5.0.0を採用した。これは記譜方式の選定であり、音程検出器の比較実験や精度改善ではない。

VexFlowのBravura版をdynamic importする。フォントは同梱データ、外部取得なし。MIT/SIL OFL 1.1の全文を `public/licenses/` に配布し画面から参照する。1ページ4小節、最大60秒/BPM240で60小節まで。楽譜chunkは約728kB（gzip約390kB）でViteの500kB警告がある。録音前の初期chunkから分離済みで、警告を設定で隠していない。実機のロード時間・CPU・メモリは未計測。

## 実録音評価・実機確認との区別

- 今回、新しい実録音の正解楽譜との比較は行っていない。採譜の音高・音価・拍子の正解率は未検証。
- 既存のPJS実録音評価は[real-audio-evaluation.md](real-audio-evaluation.md)。一人・6ファイルで経路を試した結果で、独立したF0/有声正解がなく、検出有声割合を精度と呼べない。
- 既存のクリーン合成音精度比較は[synthetic-report.md](synthetic-report.md)。今回、解析器は変更せず比較ベンチマークを再実行していない。
- iPhone Safari / Android Chromeの実機マイク、デスクトップの物理マイク、OS中断、実環境ノイズは今回も未検証。Docker Chromiumをその代わりの証拠にしない。
- 全ブラウザmatrix、Lighthouse、実機性能は未実行。対象端末評価・リリース前の確認が必要。ピアノ音声出力自体は無変更のため既存OfflineAudioContext成功証拠を再利用する。
